# Coding Workshop Registration System

A full-stack web application for browsing programming workshops and managing participant registrations.

## Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend:** PHP OOP, PDO, REST API
- **Database:** MySQL
- **Tools:** Git, GitHub, Postman

## Core Features

- Browse published workshops and view available seats.
- Register for workshops and cancel registrations.
- Prevent duplicate registrations and overbooking.
- Admin dashboard for workshop management.
- Authentication and role-based authorization.

## Project Structure

- `public/` — Frontend files and assets.
- `src/` — PHP application logic and API components.
- `routes/` — API route definitions.
- `database/` — Database schema and seed data.
- `tests/` — Application tests.
